About Skipjack

Skipjack transforms Maryland election data from scattered government PDFs and spreadsheets into clean, explorable datasets. Named after Maryland's state boat — the Chesapeake Bay skipjack — the project aims to make election data navigable and traceable. Questions? Email Derek Willis at dpwillis@umd.edu.

Methodology

Original files are downloaded from the Maryland State Board of Elections and stored as-is in an archive with SHA-256 checksums. Each file is then parsed into structured CSV format with a provenance sidecar recording the source, parse date, and parser version. The CSVs are loaded into a SQLite database for fast querying by the web application. Each report is checked against its own printed totals; the reports that do not add up are listed on the errata page.
