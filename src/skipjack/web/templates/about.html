About Skipjack

Skipjack transforms Maryland election data from scattered government PDFs and spreadsheets into clean, explorable datasets. Named after Maryland's state boat — the Chesapeake Bay skipjack — the project aims to make election data accessible and traceable.

Data Sources

All data comes from official government sources. Every number on this site traces back to its original document through our provenance system.

Methodology

Original files are downloaded from the Maryland State Board of Elections and stored as-is in an archive with SHA-256 checksums. Each file is then parsed into structured CSV format with a provenance sidecar recording the source, parse date, and parser version. The CSVs are loaded into a SQLite database for fast querying by the web application.
