# `skipjack get` Data CLI Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add read-only `skipjack list` and `skipjack get registration|results|turnout|county`
commands that print JSON (default) or CSV, from the published skipjack site or, for results and
turnout, live from the State Board.

**Architecture:** The site build writes two new machine-readable outputs under `downloads/`: a
catalog (`index.json`) and one history document per county (`county/<slug>.json`). A new
`skipjack.client` package reads those and the existing download files over HTTP (or from a local
`downloads/` folder), filters rows and renders them. The SBE source reuses the pipeline's readers
in memory and never writes to `archives/` or `data/`.

**Tech Stack:** Python 3.13, argparse, httpx, stdlib `csv`/`json`, polars (only inside the
existing pipeline readers), pytest. Design: `docs/plans/2026-11-23-data-cli-design.md`.

**Conventions for every task**

- Work on `main`; commit after each task. Commit messages are lowercase, `area: what changed`
  (see `git log --oneline`), ending with the `Co-Authored-By` line the session supplies.
- Run tests with `uv run pytest <path> -q`. Lint with `uv run ruff check src tests` and
  `uv run ruff format src tests` before each commit.
- Tests that need `skipjack.db` use the `needs_db` skip marker pattern from
  `tests/test_static_site.py:21-34`. Build it with `make build-db` if it is missing.
- No test touches the network.

**One change from the design doc:** `--data-dir` is dropped. `--base-url` accepts either a URL or
a local folder (a built site's `downloads/`, e.g. `site/downloads` after `make site`), which
covers offline use with one option instead of two.

```python
"""A machine-readable index of the downloads, for the data CLI (skipjack.client).

Built from download_files(), so it lists exactly what the site offers: the publish gates in
skipjack.web.downloads decide, not this module. Paths are relative to downloads/.
"""

from __future__ import annotations

from pathlib import Path

from skipjack.pipeline.results import COUNTY_CODES, RESULTS_ELECTIONS
from skipjack.pipeline.turnout import ELECTIONS
from skipjack.web.downloads import download_files
from skipjack.web.urls import slugify

CATALOG_VERSION = 1
REGISTRATION_TABLES = {
    "monthly": "combined/registration_monthly_all.csv",
    "activity": "combined/registration_activity_all.csv",
    "summary": "combined/registration_summary_all.csv",
}


def build_catalog(data_dir: Path) -> dict:
    months: list[str] = []
    results: dict[str, dict] = {}
    turnout: dict[str, dict] = {}
    for relative in download_files(data_dir):
        if relative.suffix != ".csv":
            continue
        parts = relative.parts
        path = relative.as_posix()
        if parts[:2] == ("voter_registration", "monthly") and len(parts) == 3:
            months.append(relative.stem)
        elif parts[0] == "results" and len(parts) == 4 and parts[2] == "county":
            _results_entry(results, parts[1], official=True, as_of=None)["files"].append(path)
        elif parts[0] == "results_unofficial" and len(parts) == 5 and parts[3] == "county":
            _results_entry(results, parts[1], official=False, as_of=parts[2])["files"].append(path)
        elif parts[0] == "turnout" and len(parts) == 5:
            code, family, geography = parts[1:4]
            entry = turnout.setdefault(code, _turnout_entry(code))
            entry["families"].setdefault(family, {}).setdefault(geography, []).append(relative.stem)
    return {
        "version": CATALOG_VERSION,
        "registration": {"tables": REGISTRATION_TABLES, "months": sorted(months)},
        "counties": [
            {"name": name, "slug": slugify(name), "code": code}
            for code, name in COUNTY_CODES.items()
        ],
        "results": results,
        "turnout": turnout,
        "county_history": "county/{slug}.json",
    }


def _results_entry(results: dict, code: str, official: bool, as_of: str | None) -> dict:
    if code not in results:
        e = RESULTS_ELECTIONS[code]
        results[code] = {
            "name": e.name,
            "election_day": e.election_day,
            "kind": e.kind,
            "official": official,
            "as_of": as_of,
            "files": [],
        }
    return results[code]


def _turnout_entry(code: str) -> dict:
    e = ELECTIONS.get(code)
    return {
        "name": e.name if e else code,
        "election_day": e.election_day if e else None,
        "certified": bool(e and e.certified),
        "families": {},
    }
```

`download_files()` returns sorted paths, so the file and as-of lists come out sorted.

```python
"""A county's whole record in one document, published as downloads/county/<slug>.json.

Registration by month, the newest publishable turnout snapshot of each report family, the
certified results rows, and the results-over-time analysis the county page shows.
"""

from __future__ import annotations

import sqlite3

from skipjack.pipeline.results import COUNTY_CODES
from skipjack.pipeline.turnout import may_publish
from skipjack.web import results_trends
from skipjack.web.downloads import results_published
from skipjack.web.urls import resolve_slug

_REGISTRATION = ["report_date", "county", "party", "party_name", "active_voters"]
_TURNOUT = [
    "as_of", "election", "family", "geography", "county", "district",
    "category", "party", "measure", "value",
]  # fmt: skip
_RESULTS = [
    "election", "county", "party_file", "office", "district", "candidate",
    "party", "winner", "write_in", "total_votes", "total_against",
]  # fmt: skip


def _rows(conn: sqlite3.Connection, sql: str, columns: list[str], params: tuple) -> list[dict]:
    return [dict(zip(columns, row, strict=True)) for row in conn.execute(sql, params)]


def county_document(
    conn: sqlite3.Connection, slug: str, cache: dict | None = None
) -> dict | None:
    """The county's document, or None for a slug that is not a Maryland county. ``cache`` is
    passed through to county_trends so a build of all 24 sums each statewide contest once."""
    county = resolve_slug(slug, COUNTY_CODES.values())
    if county is None:
        return None
    registration = _rows(
        conn,
        f"SELECT {', '.join(_REGISTRATION)} FROM voter_registration "  # noqa: S608
        "WHERE county = ? ORDER BY report_date, party",
        _REGISTRATION,
        (county,),
    )
    turnout = [
        row
        for row in _rows(
            conn,
            f"SELECT {', '.join(_TURNOUT)} FROM turnout_counts t "  # noqa: S608
            "WHERE geography = 'county' AND county = ? AND as_of = ("
            "  SELECT MAX(as_of) FROM turnout_counts"
            "  WHERE election = t.election AND family = t.family AND geography = 'county')"
            " ORDER BY election, family, category, party, measure",
            _TURNOUT,
            (county,),
        )
        if may_publish(row["election"], row["family"])
    ]
    results = [
        row
        for row in _rows(
            conn,
            f"SELECT {', '.join(_RESULTS)} FROM results_county "  # noqa: S608
            "WHERE county = ? ORDER BY election, party_file, office, district, id",
            _RESULTS,
            (county,),
        )
        if results_published(row["election"])
    ]
    return {
        "county": county,
        "slug": slug,
        "registration": registration,
        "turnout": turnout,
        "results": results,
        "results_over_time": results_trends.county_trends(conn, slug, cache),
    }
```

```python
"""Rendering: a JSON envelope of meta and rows, or the rows alone as CSV."""

from __future__ import annotations

import csv
import io
import json

_COUNT_COLUMNS = {"active_voters", "value", "winner", "write_in"}
_COUNT_SUFFIXES = ("_votes", "_against")


def _is_count(column: str) -> bool:
    return column in _COUNT_COLUMNS or column.endswith(_COUNT_SUFFIXES)


def typed(rows: list[dict]) -> list[dict]:
    """CSV rows with their count columns as int (blank: None). Other columns are untouched,
    so a district "06" or a county code "01" stays text."""

    def convert(column: str, value):
        if not _is_count(column) or not isinstance(value, str):
            return value
        if value == "":
            return None
        try:
            return int(value)
        except ValueError:
            return value

    return [{k: convert(k, v) for k, v in row.items()} for row in rows]


def render(meta: dict, rows: list[dict], fmt: str) -> str:
    if fmt == "json":
        return json.dumps({"meta": meta, "rows": rows}, indent=1) + "\n"
    if not rows:
        return ""
    columns = list(dict.fromkeys(k for row in rows for k in row))
    out = io.StringIO()
    writer = csv.DictWriter(out, fieldnames=columns, lineterminator="\n")
    writer.writeheader()
    writer.writerows(rows)  # DictWriter writes None as an empty cell
    return out.getvalue()
```

```python
"""Where the data CLI reads from: the published skipjack downloads, by URL or local folder."""

from __future__ import annotations

import csv
import io
import json
from pathlib import Path

import httpx

DEFAULT_BASE_URL = "https://newsappsumd.github.io/skipjack/downloads"
SUPPORTED_CATALOG = 1


class ClientError(Exception):
    """A failure the user can act on; the CLI prints it and exits 2."""


class SkipjackSource:
    """``base`` is the downloads/ root: a URL, or a folder such as site/downloads."""

    def __init__(self, base: str, transport: httpx.BaseTransport | None = None):
        self.base = base.rstrip("/")
        self.local = None if base.startswith(("http://", "https://")) else Path(base)
        self._transport = transport
        self._catalog: dict | None = None

    def url(self, path: str) -> str:
        return str(self.local / path) if self.local else f"{self.base}/{path}"

    def text(self, path: str) -> str:
        if self.local:
            target = self.local / path
            if not target.is_file():
                raise ClientError(f"not found: {target}")
            return target.read_text(encoding="utf-8")
        try:
            with httpx.Client(
                transport=self._transport, timeout=30.0, follow_redirects=True
            ) as client:
                response = client.get(self.url(path))
        except httpx.HTTPError as err:
            raise ClientError(f"could not reach {self.url(path)} ({err})") from err
        if response.status_code == 404:
            raise ClientError(f"not found: {self.url(path)}")
        if response.status_code != 200:
            raise ClientError(f"{self.url(path)}: HTTP {response.status_code}")
        return response.text

    def rows(self, path: str) -> list[dict]:
        return list(csv.DictReader(io.StringIO(self.text(path))))

    def catalog(self) -> dict:
        if self._catalog is None:
            try:
                catalog = json.loads(self.text("index.json"))
            except ClientError as err:
                raise ClientError(
                    f"{err}. No index.json there: point --base-url at a skipjack downloads/ "
                    "folder or URL built after the data CLI was added"
                ) from err
            if catalog.get("version", 0) > SUPPORTED_CATALOG:
                raise ClientError("the site's catalog is newer than this skipjack; upgrade it")
            self._catalog = catalog
        return self._catalog
```

```python
"""skipjack list and skipjack get: the argument parsers and what each command returns.

Every handler returns (meta, rows); run() adds the shared meta fields and renders.
"""

from __future__ import annotations

import argparse
import os
import sys
from datetime import UTC, datetime
from pathlib import Path

from skipjack.client.output import render, typed
from skipjack.client.sources import DEFAULT_BASE_URL, ClientError, SkipjackSource


def _shared(parser: argparse.ArgumentParser, sbe: bool = False) -> None:
    parser.add_argument("--format", choices=["json", "csv"], default="json")
    parser.add_argument("-o", "--output", type=Path, help="Write to a file instead of stdout")
    parser.add_argument(
        "--base-url",
        default=os.environ.get("SKIPJACK_URL", DEFAULT_BASE_URL),
        help="The skipjack downloads/ root: a URL or a local folder (env: SKIPJACK_URL)",
    )
    if sbe:
        parser.add_argument(
            "--source",
            choices=["skipjack", "sbe"],
            default="skipjack",
            help="skipjack: the published, checked files. sbe: the State Board's file, now",
        )


def register(sub: argparse._SubParsersAction) -> None:
    list_p = sub.add_parser("list", help="List the elections, counties or turnout reports")
    list_p.add_argument("what", choices=["elections", "counties", "turnout"])
    list_p.add_argument("election", nargs="?", help="For 'turnout': the election code")
    _shared(list_p)

    get_p = sub.add_parser("get", help="Print a dataset as JSON or CSV")
    get_sub = get_p.add_subparsers(dest="dataset", required=True)

    reg = get_sub.add_parser("registration", help="Voter registration by month")
    reg.add_argument("--table", choices=["monthly", "activity", "summary"], default="monthly")
    reg.add_argument("--county")
    reg.add_argument("--party", help="A party code, e.g. DEM")
    reg.add_argument("--from", dest="start", metavar="YYYY-MM")
    reg.add_argument("--to", dest="end", metavar="YYYY-MM")
    _shared(reg, sbe=True)


# ---- helpers ---------------------------------------------------------------------------------


def _county(catalog: dict, given: str | None) -> dict | None:
    """The catalog's county for a name or slug, case-insensitively; None when not asked for."""
    if given is None:
        return None
    wanted = given.strip().lower()
    for county in catalog["counties"]:
        if wanted in (county["name"].lower(), county["slug"]):
            return county
    names = ", ".join(c["name"] for c in catalog["counties"])
    raise ClientError(f"unknown county {given!r}; one of: {names}")


def _choice(kind: str, given: str, choices) -> str:
    choices = sorted(choices)
    if given not in choices:
        raise ClientError(f"unknown {kind} {given!r}; one of: {', '.join(choices)}")
    return given


# ---- list ------------------------------------------------------------------------------------


def _list(args: argparse.Namespace, source: SkipjackSource) -> tuple[dict, list[dict]]:
    catalog = source.catalog()
    if args.what == "counties":
        rows = catalog["counties"]
    elif args.what == "elections":
        rows = [
            {"code": code, "dataset": dataset, "name": e["name"],
             "election_day": e["election_day"],
             "official": e["official"] if dataset == "results" else e["certified"]}
            for dataset in ("results", "turnout")
            for code, e in catalog[dataset].items()
        ]  # fmt: skip
        rows.sort(key=lambda r: (r["election_day"] or "", r["dataset"]), reverse=True)
    else:
        if not args.election:
            raise ClientError("list turnout needs an election code, e.g. skipjack list turnout GG26")
        election = catalog["turnout"][_choice("election", args.election.upper(), catalog["turnout"])]
        rows = [
            {"family": family, "geography": geography, "snapshots": len(dates),
             "first": dates[0], "latest": dates[-1]}
            for family, geographies in election["families"].items()
            for geography, dates in geographies.items()
        ]  # fmt: skip
    return {"dataset": f"list {args.what}", "source_urls": [source.url("index.json")]}, rows


# ---- get registration ------------------------------------------------------------------------


def _registration(args: argparse.Namespace, source: SkipjackSource) -> tuple[dict, list[dict]]:
    if args.source == "sbe":
        raise ClientError(
            "registration is not parsed live: the board's monthly PDFs need OCR and skipjack's "
            "checked errata. Use --source skipjack"
        )
    catalog = source.catalog()
    county = _county(catalog, args.county)
    path = catalog["registration"]["tables"][args.table]
    if args.county and args.table == "summary":
        raise ClientError("the summary table is statewide; drop --county")
    party = args.party.upper() if args.party else None
    rows = []
    for row in source.rows(path):
        month = row["report_date"][:7]
        if county and row["county"] != county["name"]:
            continue
        if party and row["party"] != party:
            continue
        if (args.start and month < args.start) or (args.end and month > args.end):
            continue
        rows.append(row)
    filters = {
        "county": county["name"] if county else None,
        "party": party,
        "from": args.start,
        "to": args.end,
    }
    meta = {
        "dataset": "registration",
        "table": args.table,
        "official": True,
        "source_urls": [source.url(path)],
        "filters": {k: v for k, v in filters.items() if v is not None},
    }
    return meta, rows


# ---- dispatch --------------------------------------------------------------------------------

_GET = {"registration": _registration}


def run(args: argparse.Namespace) -> None:
    source = SkipjackSource(args.base_url)
    try:
        if args.command == "list":
            meta, rows = _list(args, source)
        else:
            meta, rows = _GET[args.dataset](args, source)
    except ClientError as err:
        print(f"error: {err}", file=sys.stderr)
        sys.exit(2)
    rows = typed(rows)
    meta = {
        **meta,
        "source": getattr(args, "source", "skipjack"),
        "rows": len(rows),
        "retrieved_at": datetime.now(UTC).isoformat(timespec="seconds"),
    }
    text = render(meta, rows, args.format)
    if args.output:
        args.output.write_text(text, encoding="utf-8")
    else:
        sys.stdout.write(text)
```

```python
"""The live source: the State Board's own files, parsed now with the pipeline's readers.

Nothing is written to archives/ or data/. Results get the readers' row-total checks; the
statewide cross-check needs every county's file and is left to `skipjack results-parse`.
"""

from __future__ import annotations

import argparse
import tempfile
from pathlib import Path

import httpx

from skipjack.client.sources import ClientError
from skipjack.web.urls import slugify

_FALLBACK = "Use --source skipjack for the published copy"


def _county_name(given: str | None, names) -> str | None:
    if given is None:
        return None
    wanted = given.strip().lower()
    for name in names:
        if wanted in (name.lower(), slugify(name)):
            return name
    raise ClientError(f"unknown county {given!r}; one of: {', '.join(names)}")


def results_rows(args: argparse.Namespace) -> tuple[dict, list[dict]]:
    from skipjack.pipeline import results as pr

    code = args.election.upper()
    if code not in pr.RESULTS_ELECTIONS:
        raise ClientError(f"unknown election {code!r}; one of: {', '.join(pr.RESULTS_ELECTIONS)}")
    e = pr.RESULTS_ELECTIONS[code]
    if not e.published:
        raise ClientError(
            f"the board has not posted {code}'s certified county files. {_FALLBACK} "
            "(the unofficial count, while it runs)"
        )
    county = _county_name(args.county, list(pr.COUNTY_CODES.values()))
    office = args.office.lower() if args.office else None
    rows, urls = [], []
    for f in pr.county_files(e):
        if f.role != "county" or (county and f.county != county):
            continue
        if args.party_file and f.party_file != args.party_file:
            continue
        status, body, detail = pr._download(f.url)
        if status == "unpublished" and f.party_file == "non":
            continue  # not every county has non-partisan contests
        if status != "ok":
            raise ClientError(f"could not get {f.url} ({detail or status}). {_FALLBACK}")
        try:
            read = pr.READERS[e.layout](body, e, f.county, f.party_file)
        except pr.ResultsParseError as err:
            raise ClientError(f"{f.file_name} did not parse: {err}. {_FALLBACK}") from err
        urls.append(f.url)
        rows += [
            row for row in read.frame.to_dicts() if office is None or office in row["office"].lower()
        ]
    filters = {"county": county, "office": args.office, "party_file": args.party_file}
    meta = {
        "dataset": "results",
        "election": code,
        "name": e.name,
        "election_day": e.election_day,
        "official": True,
        "as_of": None,
        "source_urls": urls,
        "checks": "row totals checked; statewide cross-check not run",
        "filters": {k: v for k, v in filters.items() if v is not None},
    }
    return meta, rows


def turnout_rows(args: argparse.Namespace) -> tuple[dict, list[dict]]:
    from skipjack.pipeline import turnout as pt

    code = args.election.upper()
    if code not in pt.ELECTIONS:
        raise ClientError(f"unknown election {code!r}; one of: {', '.join(pt.ELECTIONS)}")
    if not args.family:
        raise ClientError("--source sbe parses one report at a time; add --family")
    if args.as_of != "latest":
        raise ClientError(
            f"the board serves only its current file, so --source sbe has no --as-of. {_FALLBACK}"
        )
    e = pt.ELECTIONS[code]
    files = [f for f in e.files if f.family == args.family and f.geography == args.geography]
    if not files:
        pairs = sorted({f"{f.family}/{f.geography}" for f in e.files})
        raise ClientError(
            f"no {args.family}/{args.geography} report for {code}; one of: {', '.join(pairs)}"
        )
    if not pt.may_publish(code, args.family):
        raise ClientError(
            f"{code} is certified, and {args.family} is the board's unofficial tally: its "
            "certified reports are the figures of record"
        )
    county = _county_name(args.county, sorted({c for c in _counties()}))
    failures = []
    for f in files:  # a family's workbook and its PDF twin: the first that parses wins
        try:
            data = pt.download(f.url)
        except httpx.HTTPError as err:
            failures.append(f"{f.url}: {err}")
            continue
        kind = pt.sniff(data)
        if kind is None:
            failures.append(f"{f.url}: not published yet")
            continue
        with tempfile.TemporaryDirectory() as tmp:
            path = Path(tmp) / f"{args.family}.{kind}"
            path.write_bytes(data)
            try:
                as_of, frame = pt.parse_path(path, code, args.family, args.geography)
            except ImportError as err:
                raise ClientError(
                    f"{args.family} is a PDF report and needs the PDF reader ({err.name}): "
                    f"install skipjack[pdf]. {_FALLBACK}"
                ) from err
            except pt.TurnoutParseError as err:
                failures.append(f"{f.url}: did not parse: {err}")
                continue
        rows = [r for r in frame.to_dicts() if county is None or r["county"] == county]
        meta = {
            "dataset": "turnout",
            "election": code,
            "name": e.name,
            "election_day": e.election_day,
            "official": e.certified,
            "as_of": {args.family: as_of or e.undated_as_of},
            "source_urls": [f.url],
            "filters": {"family": args.family, "geography": args.geography}
            | ({"county": county} if county else {}),
        }
        return meta, rows
    raise ClientError("; ".join(failures) + f". {_FALLBACK}")


def _counties() -> list[str]:
    from skipjack.pipeline.results import COUNTY_CODES

    return list(COUNTY_CODES.values())
```

**Step 2: README section**

Add after the "Commands" table:

````markdown
## Pulling the data from the command line

`skipjack get` prints any of the published datasets as JSON (the default) or CSV. It needs
nothing but the package, not a checkout:

```bash
uvx --from git+https://github.com/NewsAppsUMD/skipjack skipjack get registration --county Howard --from 2024-01
```

| Command | What it prints |
|---|---|
| `skipjack list elections` / `counties` / `turnout GG26` | What there is to ask for |
| `skipjack get registration [--table monthly\|activity\|summary] [--county] [--party] [--from] [--to]` | Registration by month |
| `skipjack get results --election GG22 [--county] [--office] [--party-file]` | An election's results by county |
| `skipjack get turnout --election GG26 [--family] [--geography] [--as-of latest\|all\|DATE] [--county]` | Turnout reports; `--as-of all` is the day-by-day trend |
| `skipjack get county "Prince George's" [--section registration\|turnout\|results]` | A county's whole record in one document |

Every command takes `--format csv`, `-o FILE` and `--base-url` (a URL or a local `downloads/`
folder such as `site/downloads`; also the `SKIPJACK_URL` environment variable).

JSON output is `{"meta": {...}, "rows": [...]}`. `meta` records where the rows came from
(`source_urls`), the snapshot (`as_of`), whether the figures are certified (`official`) and the
filters applied. CSV output is the rows alone.

By default the data comes from this site's published files, which have been through the checks
described under "Accuracy". `--source sbe` instead downloads the State Board's own file and
parses it on the spot, for results and turnout only. It reflects the board's file as of that
moment, checks row totals but not the statewide cross-check, and fails rather than fall back if
the board's file is missing or does not parse. Turnout reports the board publishes as PDF need
the PDF reader: `skipjack[pdf]`.
````
